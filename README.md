# Kosaraju Weaves by Jayasri

Website for Kosaraju Weaves, a handloom saree boutique at BNR Hills, Raidurg, Hyderabad.

- Live site: https://saicharan13579-source.github.io/kosaraju-weaves/
- Static site: `index.html` with photos in `img/` and reels in `vid/`. No build step.
- Hosting: GitHub Pages from the `main` branch, root folder.
